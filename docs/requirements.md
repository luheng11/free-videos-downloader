# 万能视频下载网站 - 需求分析文档

## 1. 项目背景

很多用户有下载保存视频到本地的需求，但面临以下痛点：
- 部分平台不支持下载功能
- 下载不够方便（不支持批量下载、有数量限制、清晰度受限等）
- 缺少统一的跨平台下载工具

## 2. 核心目标

开发一个万能视频下载网站，让用户能够快速、随时随地、从各个平台下载视频，手机上也能使用。

## 3. 用户需求

### 3.1 核心需求
| 需求 | 优先级 | 说明 |
|------|--------|------|
| 单视频下载 | P0 | 粘贴链接 -> 解析 -> 选择格式 -> 下载 |
| 多平台支持 | P0 | 支持 YouTube、B站、抖音等 1800+ 平台 |
| 手机端可用 | P0 | 响应式设计，手机浏览器直接使用 |
| 多清晰度选择 | P0 | 支持多种分辨率和格式（含仅音频） |

### 3.2 付费功能需求
| 需求 | 优先级 | 说明 |
|------|--------|------|
| 批量下载 | P1 | 多行链接输入，批量解析下载 |
| AI 视频总结 | P1 | 基于字幕生成视频内容摘要 |
| 字幕翻译 | P1 | 下载字幕并翻译为目标语言 |
| 会员体系 | P1 | 免费 3 次/天 vs 会员无限 |

### 3.3 扩展需求（阶段 5）
| 需求 | 优先级 | 说明 |
|------|--------|------|
| 字幕下载 | P2 | 单独下载视频字幕文件 |
| 下载进度 | P2 | 实时显示下载进度条 |
| 历史记录 | P2 | 本地存储下载历史 |
| 移动端优化 | P2 | 触控友好交互 |

## 4. 技术约束

- **不使用数据库**：保持轻量，内存任务队列 + localStorage
- **站在巨人的肩膀上**：直接使用 yt-dlp 开源项目（GitHub 14w+ Star，支持 1800+ 网站）
- **最小改动封装**：直接调用 yt-dlp Python API，不修改源码

## 5. 下载模式策略

| 场景 | 策略 | 原因 |
|------|------|------|
| 直链可用且未过期 | 直链重定向（302） | 不占服务器资源 |
| 直链不可用/有防盗链 | 服务端代理下载 | 保证可用性 |
| 大文件(>500MB) | 服务端流式传输 | 避免内存溢出 |

用户无需手动选择，后端自动判断最优路径。

## 6. UI 设计要求

- 参考 https://ai.codefather.cn/painting 的 UI 风格
- 配色：深蓝 `#0F172A` + 亮蓝 `#1777FF`，白色背景
- 按钮：主按钮亮蓝胶囊形，次按钮白底圆角带阴影
- 布局：顶部大标题 + 副标题 + 居中输入框，卡片网格
- 突出付费引导（VIP 角标、权益对比表、限制功能遮罩）
